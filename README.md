# Cyberbullying Detection Using NLP and Machine Learning

## Project Objective
This project focuses on cleaning, preprocessing, analyzing, and visualizing cyberbullying social media text data.

## Features
- Missing value handling
- Duplicate removal
- Text preprocessing
- Stopword removal
- Data visualization
- Word cloud analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- NLTK
- WordCloud

## Project Structure
- dataset.csv
- cleaned_cyberbullying_dataset.csv
- data_cleaning_visualization.ipynb

## Future Scope
- TF-IDF vectorization
- Machine learning classification
- Cyberbullying prediction system
